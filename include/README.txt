This c64.h is a modified copy of cc65's system header, patched for Qt
Creator's Clang code model (clangd) to prevent false error squiggles.

It is NOT used during compilation. The actual build uses the real cc65
header at /usr/share/cc65/include/c64.h via cl65's built-in include path.

Do not edit this file for compilation purposes. If you need system
definitions, modify /usr/share/cc65/include/c64.h instead.
